* Method and assumptions

- Method class :: Experiment analysis — a within-subject cumulative
  ablation with a single rater, reported descriptively.
- Method :: Preprocessing is a staircase of five cumulative stages.
  Each article is rendered at the stages that bite hardest on it, under
  three models, and scored blind.

** Preprocessing stages

Stages are cumulative and applied in this order.

| Stage | Name | What it does |
|-------+------+--------------|
| P0 | none | The clipping exactly as =clip= wrote it, front matter included. |
| P1 | preamble | Front matter becomes a spoken opening: title, author with =[[...]]= stripped, publication date, then a pause. =tags=, =created=, and =source= are dropped. |
| P2 | structural strip | Drop =![](images/...)= references. Markdown links become their link text; the URL is dropped. Remove newsletter chrome. Headings are spoken with a pause, not as bare fragments. Blockquotes get an attribution cue so the narrator does not appear to contradict himself. |
| P3 | normalisation | NFC normalise. Smart quotes to ASCII, em and en dashes to clause breaks, ellipsis to a full stop, non-breaking space to space. Strip zero-width and control characters. |
| P4 | spoken forms | Expand numbers, currencies, percentages, dates, and ranges to spoken form. Handle full-caps lead-ins so they are read as words, not spelled out. |
| P5 | respelling | Apply a term-to-respelling table (for example =Vikaas Purush= to =Vee-kaas Poo-roosh=). Neither model documents SSML or phoneme tags, so a "pronunciation lexicon" here is a plain substitution table. |

** Render design

Chunk size is held fixed at *paragraph-grouped chunks of about 400
words, never splitting mid-sentence*, for every render in the ablation,
so that chunk-seam artefacts do not confound the text comparison. Chunk
size gets its own small comparison at the end.

| Passage | Conditions | Models | Renders |
|---------+------------+--------+---------|

** Scoring

Each excerpt render is scored on six named failure modes, each on a
0–3 scale where 0 is "not present" and 3 is "ruins the listen":

1. Gibberish or garbled words.
2. Mispronounced names, places, or acronyms.
3. Numbers, dates, or currency read wrongly.
4. Chrome read aloud that should not have been.
5. Volume or pace discontinuity at a chunk seam.
6. Unnatural pauses or run-on sentences.

Playback order is randomised with a recorded seed and labels are hidden
until scoring is complete.

** Assumptions

- One listener, so scores are a preference record, not an estimate of
  anything.
- Because the staircase is cumulative, each stage's effect is
  conditional on the stages before it and is not separable from them.
- The P5 respelling table is *derived from listening to the P0 and P3
  baselines*. Its improvement is therefore fitted to errors already
  observed. It shows that the fix worked, not that lexicons help in
  general.
- The Deepgram leg changes vendor and voice at once. MAI-Voice-2
  against MAI-Voice-2-Flash is the clean model-tier comparison;
  Deepgram is a separate "is free good enough" question.
- The =/audio/speech= endpoint has no seed parameter, so synthesis is
  non-deterministic and two renders of identical text may differ.

** Limits

Two articles, one listener, English only, no inter-rater reliability,
no statistical test, and no claim of generalisation beyond these two
pieces.

* Human review boundary

** Claim-critical logic

Every preprocessing stage (P1 through P5), the chunker, excerpt
extraction, the blinding and randomisation, score aggregation, and the
manifest hashing.

** Human-review-critical logic

These can produce plausible but wrong output without looking broken:

- *Structural strip (P2).* A greedy chrome regex can eat body prose and
  the result still sounds like a well-formed article. The only real
  oracle is reading the diff.
- *Spoken-form expansion (P4).* "1498" read as "one thousand four
  hundred and ninety-eight" instead of "fourteen ninety-eight" is
  wrong, fluent, and invisible to any automated check.
- *The respelling table (P5).* Subjective, and capable of making
  pronunciation worse.
- *Excerpt extraction.* A silently wrong excerpt invalidates every
  downstream comparison while everything continues to run.
- *The score sheet and its interpretation.*

** Logic excluded from human review

| Component | Plausible failure | Independent oracle | Fault probe | Runs in the workflow |
|-----------+-------------------+--------------------+-------------+----------------------|
| OpenRouter client | Wrong model or voice sent; request silently fails | Response headers record the model; =X-Generation-Id= and HTTP status stored per render | Test asserting a non-200 raises rather than writing a file | =verify.sh= |
| MP3 writing | Zero-byte or truncated file | File size and =ffprobe= duration against expected words-per-minute | Test with a truncated byte stream | =verify.sh= |
| Loudness measurement | Wrapper misparses =ebur128= output | Known-loudness fixture WAV generated by =ffmpeg= at a set level | Test asserting the parsed LUFS matches the generated level | =verify.sh= |
| Manifest CSV writer | Dropped or misaligned row | Row count asserted equal to render count; key uniqueness asserted | Test writing a duplicate key | =verify.sh= |
| =afplay= Org link | Does not play | Immediately obvious to the user | None | Not applicable |

All four failures above are loud: they raise, or they produce a file
whose size or duration assertion fails.

import requests

MODELS = (
    ("deepgram/flux-tts:free", "flux-haley-en", 0),

    ("microsoft/mai-voice-2", "en-US-Harper:MAI-Voice-2", 22),
)
INITIAL_LENGTHS = (2_000, 5_000, 10_000, 20_000)
MAXIMUM_LENGTH = 160_000
SPEND_CEILING_USD = 10.00
SENTENCE = "The quick brown fox jumps over the lazy dog. "

key = os.environ.get("OPENROUTER_API_KEY")
if not key:
    raise RuntimeError("OPENROUTER_API_KEY is required.")

spent = 0.0


def cost(rate, characters):
    return rate * characters / 1_000_000


def attempt(model, voice, rate, characters):
    global spent
    if spent + cost(rate, characters) > SPEND_CEILING_USD:
        return "budget", None
    text = (SENTENCE * (characters // len(SENTENCE) + 1))[:characters]
    print(f"{model} {characters}", file=sys.stderr, flush=True)
    try:
        response = requests.post(
            "https://openrouter.ai/api/v1/audio/speech",
            headers={"Authorization": f"Bearer {key}"},
            json={
                "model": model,
                "input": text,
                "voice": voice,
                "response_format": "mp3",
                "speed": 1,
            },
            timeout=180,
            stream=True,
        )
    except requests.Timeout:
        spent += cost(rate, characters)
        return "timeout", None
    except requests.RequestException as error:
        return "error", str(error)[:200]
    spent += cost(rate, characters)
    with response:
        content_type = response.headers.get("Content-Type", "")
        if response.status_code == 200 and content_type.startswith("audio/mpeg"):
            return "accepted", None
        snippet = response.content[:200].decode("utf-8", "replace").replace("\n", " ")
        return "rejected", f"{response.status_code} {snippet}"


def probe(model, voice, rate):
    attempts = []
    last_accepted = 0
    first_failed = None
    stop = None

    def one(characters):
        nonlocal last_accepted, first_failed, stop
        status, detail = attempt(model, voice, rate, characters)
        attempts.append(f"{characters} {status}")
        if status == "accepted":
            last_accepted = characters
            return
        if status == "rejected":
            first_failed = characters
            return
        stop = status if detail is None else f"{status}: {detail}"

    for characters in INITIAL_LENGTHS:
        one(characters)
        if stop or first_failed is not None:
            break
    else:
        characters = INITIAL_LENGTHS[-1] * 2
        while characters <= MAXIMUM_LENGTH and stop is None and first_failed is None:
            one(characters)
            characters *= 2

    if stop is None and first_failed is not None:
        low, high = last_accepted, first_failed
        while stop is None and high - low > 1:
            midpoint = (low + high) // 2
            one(midpoint)
            if stop is not None:
                break
            if last_accepted >= midpoint:
                low = last_accepted
            else:
                high = first_failed

    if stop == "budget":
        conclusion = "stopped before exceeding the $10 estimate"
    elif stop:
        conclusion = f"stopped: {stop}"
    elif first_failed is None:
        conclusion = f"no failure through {MAXIMUM_LENGTH} characters"
    else:
        conclusion = "bisection completed"
    print(
        f"{model}: maximum_accepted={last_accepted} "
        f"first_failed={first_failed} {conclusion}"
    )
    print("  " + "; ".join(attempts))


for model, voice, rate in MODELS:

** Sentence-safe chunks

pySBD 0.3.4 identifies English sentence spans. The chunker slices the
original text at those offsets, preserving every character; it keeps
whole paragraphs together when they fit and splits longer paragraphs at
sentence boundaries. The round-trip assertion checks the spans.

#+begin_src python :tangle no :session *tts* :results output replace
import pysbd

sentence_segmenter = pysbd.Segmenter(language="en", clean=False, char_span=True)

def make_chunks(text, word_limit=350, char_limit=1900):
    paragraphs = re.split(r"(\n{2,})", text)
    chunks, current = [], ""
    for index in range(0, len(paragraphs), 2):
        paragraph = paragraphs[index]
        separator = paragraphs[index + 1] if index + 1 < len(paragraphs) else ""
        unit = paragraph + separator
        if len(unit.split()) <= word_limit and len(unit) <= char_limit:
            if current and (len((current + unit).split()) > word_limit or
                            len(current + unit) > char_limit):
                chunks.append(current)
                current = unit
            else:
                current += unit
            continue
        spans = sentence_segmenter.segment(unit)
        sentences = [unit[span.start:span.end] for span in spans]
        if "".join(sentences) != unit:
            raise ValueError("Sentence spans did not preserve the source text")
        for sentence in sentences:
            candidate = current + sentence
            if len(sentence) > char_limit or len(sentence.split()) > word_limit:
                raise ValueError("A single sentence exceeds a chunk budget")
            if current and (len(candidate.split()) > word_limit or len(candidate) > char_limit):
                chunks.append(current)
                current = sentence
            else:
                current = candidate
    if current:
        chunks.append(current)
    assert "".join(chunks) == text
    assert all(len(c.split()) <= word_limit and len(c) <= char_limit for c in chunks)
    return chunks

"""Independent audio checks for the TTS preprocessing experiment."""

from __future__ import annotations

import difflib
import hashlib
import json
import re
import subprocess
import tempfile
import unicodedata
from pathlib import Path

WHISPER_MODEL = "mlx-community/whisper-tiny"
MAX_WER = 0.02
MAX_SEAM_DELTA_LU = 3.0
MAX_PLAUSIBLE_WPM = 360


def words(text: str) -> list[str]:
    """Tokenise speech text without case or punctuation differences."""
    normalised = unicodedata.normalize("NFKC", text).casefold()
    return re.findall(r"[\w]+(?:['’][\w]+)?", normalised, flags=re.UNICODE)


def word_error_rate(reference: str, hypothesis: str) -> float:
    """Return word-level Levenshtein distance divided by reference words."""
    expected, actual = words(reference), words(hypothesis)
    if not expected:
        return 0.0 if not actual else 1.0
    previous = list(range(len(actual) + 1))
    for row, expected_word in enumerate(expected, 1):
        current = [row]
        for column, actual_word in enumerate(actual, 1):
            current.append(min(
                current[-1] + 1,
                previous[column] + 1,
                previous[column - 1] + (expected_word != actual_word),
            ))
        previous = current
    return previous[-1] / len(expected)


def word_diff(reference: str, hypothesis: str) -> str:
    """Render a readable word-level diff for human review."""
    return "\n".join(difflib.unified_diff(
        words(reference), words(hypothesis), fromfile="sent", tofile="heard", lineterm=""
    ))


def probe_duration(audio_path: Path) -> float:
    result = subprocess.run(
        ["ffprobe", "-v", "error", "-show_entries", "format=duration", "-of", "json", str(audio_path)],
        check=True, capture_output=True, text=True,
    )
    return float(json.loads(result.stdout)["format"]["duration"])


def integrated_loudness(audio_path: Path) -> float:
    result = subprocess.run(
        ["ffmpeg", "-hide_banner", "-nostats", "-i", str(audio_path), "-filter_complex", "ebur128=framelog=verbose", "-f", "null", "-"],
        check=True, capture_output=True, text=True,
    )
    matches = re.findall(
        r"Integrated loudness:\s*I:\s*(-?\d+(?:\.\d+)?)\s*LUFS", result.stderr
    )
    if not matches:
        raise ValueError(f"ffmpeg did not report integrated loudness for {audio_path}")
    return float(matches[-1])


def transcribe(audio_path: Path, model: str = WHISPER_MODEL) -> str:
    """Transcribe locally with Whisper running through Apple's MLX runtime."""
    try:
        import mlx_whisper
    except ImportError as error:
        raise RuntimeError("Install mlx-whisper in the experiment Python environment") from error
    response = mlx_whisper.transcribe(
        str(audio_path), path_or_hf_repo=model, language="en", condition_on_previous_text=False
    )
    transcript = response.get("text", "").strip()
    if not transcript:
        raise ValueError(f"Whisper returned an empty transcript for {audio_path}")
    return transcript


def duration_metrics(text: str, seconds: float) -> dict[str, float | bool]:
    expected = len(words(text))
    minimum = expected * 60 / MAX_PLAUSIBLE_WPM
    return {
        "duration_seconds": round(seconds, 3),
        "expected_min_duration_seconds": round(minimum, 3),
        "duration_flag": seconds < minimum,
    }


def add_seam_metrics(rows: list[dict[str, object]], threshold: float = MAX_SEAM_DELTA_LU) -> None:
    """Add each next-chunk loudness change to its left-hand render row."""
    for index, row in enumerate(rows):
        if index + 1 == len(rows):
            row["seam_delta_lu"] = ""
            row["seam_flag"] = False
            continue
        delta = abs(float(row["loudness_lufs"]) - float(rows[index + 1]["loudness_lufs"]))
        row["seam_delta_lu"] = round(delta, 2)
        row["seam_flag"] = delta > threshold


def check_loudness_fixture() -> float:
    """Generate a calibrated -23 LUFS tone and check ffmpeg parses it."""
    with tempfile.TemporaryDirectory() as directory:
        fixture = Path(directory) / "known-level.wav"
        subprocess.run([
            "ffmpeg", "-hide_banner", "-loglevel", "error", "-f", "lavfi", "-i",
            "sine=frequency=1000:duration=5", "-af", "volume=0.8",
            "-c:a", "pcm_s16le", str(fixture),
        ], check=True, capture_output=True, text=True)
        measured = integrated_loudness(fixture)
    if abs(measured - (-23.0)) > 0.5:
        raise AssertionError(f"Expected fixture at -23 LUFS, parsed {measured:.2f} LUFS")
    return measured


def analyse_render(
    audio_path: Path,
    text: str,
    transcript_path: Path,
    diff_path: Path,
    cached_transcript: str | None = None,
    model: str = WHISPER_MODEL,
) -> dict[str, object]:
    transcript = cached_transcript if cached_transcript is not None else transcribe(audio_path, model)
    transcript_path.parent.mkdir(parents=True, exist_ok=True)
    diff_path.parent.mkdir(parents=True, exist_ok=True)
    transcript_path.write_text(transcript + "\n", encoding="utf-8")
    diff = word_diff(text, transcript)
    diff_path.write_text(diff + ("\n" if diff else ""), encoding="utf-8")
    wer = word_error_rate(text, transcript)
    experiment_root = Path(__file__).resolve().parent
    return {
        "transcript_file": str(transcript_path.resolve().relative_to(experiment_root)),
        "word_diff_file": str(diff_path.resolve().relative_to(experiment_root)),
        "audio_sha256": hashlib.sha256(audio_path.read_bytes()).hexdigest(),
        "asr_model": model,
        "wer": round(wer, 5),
        "wer_flag": wer > MAX_WER,
        **duration_metrics(text, probe_duration(audio_path)),
        "loudness_lufs": round(integrated_loudness(audio_path), 2),
    }

for row in clips:
    sent_text = (root / row["sent_text_file"]).read_text(encoding="utf-8")
    words = len(sent_text.split())
    duration = float(row["duration_seconds"])
    seam = row["seam_delta_lu"]
    measurements.append({
        "article": row["article"],
        "clip": Path(row["filename"]).stem.rsplit("-", 1)[-1],
        "words": words,

        "wer_flag": row["wer_flag"],
        "duration": duration,
        "rate_wpm": words * 60 / duration,
        "lufs": float(row["loudness_lufs"]),
        "seam": None if seam == "" else float(seam),
        "seam_flag": row["seam_flag"],
    })

durations = [item["duration"] for item in measurements]
rates = [item["rate_wpm"] for item in measurements]

seams = [item["seam"] for item in measurements if item["seam"] is not None]
duration_flags = sum(
